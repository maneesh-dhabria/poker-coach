**Architecture & consistency reviewer — PASS.** `core/mental/*` is pure (no React/Next/DOM/component imports); the component reads `buildMentalEstimate(...)` results and reuses the existing `requestEquity` worker client rather than recomputing — matching the `FeedbackPanel`/`DecisionAnalysis` contract (CLAUDE.md §17). `sessionStore` wiring (`mentalMathOpen` + setter) and the FeedbackPanel integration (rendered after the EV block, no new tab) match the spec. **Bug-scan reviewer — 1 High-severity bug (confidence 88), FIXED.**

> **Bug:** `MentalMathSection` memoized its derived input as `useMemo(() => inputFromFlow(flow), [flow])`. But `gameStore` creates **one** `HandFlow` instance per hand (`gameStore.ts:104`) and thereafter **mutates it in place** (`heroAct` → `flow.heroAct(...)`), bumping only `tick`. `flow`'s identity is stable for the whole hand, so the memo ran once and froze the estimate at its first snapshot — the section never advanced flop→turn→river. This **defeats the feature's core purpose** (live-hand teaching) and directly violates **FR-02 / spec §3.1** ("Re-derives on `gameStore.tick` … so it tracks the live hand"). It slipped past the unit tests because they inject a fresh `flow` object per scenario (new identity), so the memo recomputed in tests but not in the live app.
>
> **Fix** (`08d966d`): re-derive the input on `tick` (`useMemo(..., [flow, tick])`), and drive the true-equity effect off the stable per-spot `equityKey` so Monte Carlo fires once per spot rather than on every tick now that `input` is a fresh object each tick. The two intentional dependency choices carry `eslint-disable-next-line` + rationale comments (exhaustive-deps cannot see that `flow` is externally mutated). Lint remains clean.

The reviewer also positively confirmed (traced by hand): Rule of 2&4 + 100 cap; hypergeometric `exactHitPct`; flush=9 / OESD=8 / gutshot=4; the Q♥J♥ on T♥9♣2♥ = 15 (9+8−2) worked example; Ace-low wheel handling; overcards-only-when-no-draw guard; made-hand guard; `Set<Card>` dedup correctness; the equity effect's `cancelled`-flag race protection.
