| # | Issue | Fix | Evidence |

| 3 | **FR-05 production crypto RNG** — production deal seed used `Math.random()`. | `prodSeed()` sources from `crypto.getRandomValues` when available; mulberry32 still expands deterministically per hand (testability preserved). `app/page.tsx`. | Typecheck + build clean; deal path exercised live. |
| 4 | **FR-52 missing ½/¾/pot quick buttons** — action bar had a min/max slider but not the named pot-relative quick-size affordance the FR requires. | Added ½/¾/Pot buttons (aria-labelled), pot plumbed via `view.pot`; targets clamped to `[minRaiseTo,maxRaiseTo]` so always legal. `ActionBar.tsx`, `PokerTable.tsx`. | 3 new tests in `ActionBar.test.tsx`; verified live (Pot on $7 pot, toCall $2 → "Raise to $9"). |
