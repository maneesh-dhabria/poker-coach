# Independent fresh-reviewer reviews

Each file `iter-NN.md` is the scratchpad of ONE independent first-time-user reviewer
subagent, run with NO memory of this game's design, of prior fixes, or of any earlier
reviewer's scratchpad. Reviewers are launched one at a time (single shared browser).

Purpose of keeping them all: see how the first-time-user experience evolves across
fix iterations. Each reviewer is independent; this folder is the only place their
notes accumulate.

- `iter-NN.md` — iteration N's reviewer scratchpad (emotions, screenshots, SUMMARY).
